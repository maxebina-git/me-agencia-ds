## 📦 Para publicar no npm:

### 1. Testar o build (opcional mas recomendado)

```bash
npm run build:lib
```

Verifique se a pasta `dist/` foi criada com:
- index.js
- index.mjs
- index.d.ts
- styles.css

### 2. Publicar

```bash
npm publish --access public
```

### 3. Verificar

Acesse: https://www.npmjs.com/package/@maxebina/max-ds

Seu pacote estará disponível!
